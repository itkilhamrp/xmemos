## Default Permission

Default permissions for the Xmemos Android/Desktop storage and biometric bridge

#### This default permission set includes the following:

- `allow-get-media-root`
- `allow-set-nomedia`
- `allow-get-nomedia-status`
- `allow-pick-document`
- `allow-save-document`
- `allow-authenticate-biometric`
- `allow-check-biometric-available`
